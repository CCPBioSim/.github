# CCPBioSim

This GitHub organisation contains software, workshop material and many other types of repositories.

The developer pages at [ccpbiosim.github.io](https://ccpbiosim.github.io/) describe our development practices and list which repositories are actively maintained. Shared defaults for our repositories, such as dependency update configuration, community-health files and reusable workflows, live in [CCPBioSim/.github](https://github.com/CCPBioSim/.github).
